# E-Store

A simple Javascript+JSON E-Store, which allows customer to favorite and add items to their cart. 

This project demonstrates clean layering (Views-Project-Data).

---
## Description

This example implements basic **CRUD operations** for an **E-Store**:

- Find a product by ID  
- List all products
- Post a favorite product     
- Delete a product  

It provides a simple foundation for learning how to structure a Javascript project with JSON, node and write maintainable code.

---

## Prerequisites

- JavaScript
- Node v24.9.0
- WebStorm (or any JavaScript IDE of choice)

---

## Getting Started

### Clone the repository

Via WebStorm

1. Open WebStorm.
2. From the Welcome screen (or File menu), choose **Get from Version Control…**
3. In the dialog that appears, paste `https://github.com/Laura-LiisParm/eStore.git` into the **URL** field.
4. Select your desired local directory and click **Clone**.
5. Once the clone completes, WebStorm will open the project—allow it to import/reload Node settings.
